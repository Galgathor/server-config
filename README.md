# server-config

Server configuration scripts and templates.

## Quick Start

### Fish Shell + Starship Setup

Cool one-liner to copy/paste for quick setup:

```bash
curl -fsSL https://raw.githubusercontent.com/Galgathor/server-config/main/setup-neat-terminal.sh | bash
```

This will:
- Install ble.sh and Starship prompt
- Configure ble.sh in ~/.bashrc
- Apply the Starship configuration from `templates/starship.toml`
