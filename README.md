# server-config

Server configuration scripts and templates.

## Quick Start

### Fish Shell + Starship Setup

Run the setup script directly from GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/Galgathor/server-config/main/setup-fish-starship.sh | bash
```

This will:
- Install Fish shell and Starship prompt
- Configure Fish as the default shell
- Apply the Starship configuration from `templates/starship.toml`
